ZANCHANGEMAKERS

Youth volunteer movement building leaders through Volunteerism, Skills & Civic Action. TZS-native donations, Swahili locale, and a free-AI chatbot that answers all queries.

Pages URL (after enable): https://angelanickson.github.io/Zanweb/

What’s inside

Django 4.2 + DRF + Neon PostgreSQL • TZS mobile-money (Snippe) • Tanzania-first UX

Donations in TZS

Snippe USSD push, webhook /api/webhooks/snippe/, til-monitoring, TSh formatting sw-TZ / TZS.

Free AI Chatbot

Pollinations.ai (Mistral/Llama, no key) via /api/chatbot/ → answers all queries, offline Swahili FAQ fallback.

Admin CRUD

Full create/read/update/delete for programs, gallery, partners, stories, donations, applications, messages — API + localStorage fallback, TZS & Dar es Salaam dates.

Tanzania Locale

LANGUAGE_CODE=sw, TIME_ZONE=Africa/Dar_es_Salaam, formatTZS → TSh 50,000, dates → 27 Ago 2026.

Roles & Auth

JWT + is_admin_role/is_coordinator guards, Neon DB, volunteer CVs, event tracking.

Frontend

Vanilla JS, responsive admin shell (admin.html), shared nav/footer/chatbot, no duplicate injection on admin.
